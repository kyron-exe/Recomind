## Overview

Recomind is a modern recommendation discovery app that helps users find top-rated movies, games, books, and software — all in one place. Browse by category, filter by genre, and explore curated content with ratings and descriptions at a glance.

## Features

- 🎬 **Multi-category browsing** — Movies, Software, Games, and Books in one unified interface
- 🎯 **Genre filtering** — Quickly narrow results by Action, Sci-Fi, Fantasy, Comedy, Drama, Thriller, Romance, and more
- ⭐ **Rating system** — Community-sourced ratings displayed on every card
- 🃏 **Card-based UI** — Clean, scannable layout with title, description, genre badge, and release year
- 🌙 **Dark mode** — Sleek dark-first design for comfortable browsing

## Getting Started

```bash
# Clone the repository
git clone https://github.com/prasadkanchanwar58-Igtm/recomind.git
cd recomind

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
