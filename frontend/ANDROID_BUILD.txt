Recomind — website + Android app (same codebase)

WEBSITE (unchanged)
  npm run dev          → http://localhost:5173
  npm run build        → deploy the "dist" folder to any static host
  In Chrome/Edge: open the deployed URL → menu "Install app" (PWA)

ANDROID APK (Capacitor)
  Prerequisites: Node, Android Studio (SDK + JDK), backend running for API calls.

  1) Build UI and copy into the Android project:
     npm run android:build

  2) Open Android Studio:
     npm run cap:android
     (or: npx cap open android)

  3) In Android Studio: Build → Build Bundle(s) / APK(s) → Build APK(s).
     Debug APK path is usually:
     android/app/build/outputs/apk/debug/app-debug.apk

  Backend URL on device and in production
  - Both physical phones and emulators require an HTTPS backend with a certificate
    trusted by the device. Create frontend/.env.production with:
      VITE_API_URL=https://YOUR_API_HOST
    then npm run android:build again. Use an HTTPS reverse proxy or tunnel in front
    of the local backend for device development; do not bypass certificate checks.
  - API URLs must point directly to the backend; API redirects are rejected.
  - Cleartext HTTP and mixed content are disabled for all Android builds, including debug.
  - npm run dev in a browser still supports http://localhost:5000 (or a loopback IP).
    LAN HTTP endpoints are rejected. Website production builds also require HTTPS.

FIX: "Parent directory of ... build.gradle\.gradle\build-attribution\... does not exist"
  This means Android Studio thinks your project root is the FILE "build.gradle" instead of the ANDROID FOLDER.

  Do this:
  1) File → Close Project.
  2) File → Open → click the FOLDER:
       ...\frontend\android
     (You must see build.gradle, settings.gradle, app\, gradle\ INSIDE that folder — do NOT open
      "build.gradle" as a file, and do NOT open "frontend" or "app" alone.)
  3) Android Studio: Settings → Build, Execution, Deployment → Gradle → Gradle user home:
     leave EMPTY (default C:\Users\<you>\.gradle) unless you know you need a custom path.
  4) File → Invalidate Caches → Invalidate and Restart.
  5) If it still fails, delete the folder frontend\android\.gradle (not the whole project), reopen android, Sync.

  Paths with spaces (e.g. "recommender-app - Copy") can confuse tools; if problems continue, copy the
  project to a path without spaces and open frontend\android from there.
